## League of Legends Statistics Discord bot

Have you wondered what champs to ban in your next clash game?
Get a visual analysis of your opponents champion pool directly in Discord.

### Setup
Invite this bot to your Discord server
https://discord.com/oauth2/authorize?client_id=644983168751108112

### Dependencies
This app was built upon
Orianna Riot Api wrapper - [orianna.merakianalytics.com](https://github.com/meraki-analytics/orianna)
and
Discord4j - https://discord4j.com
